# Как предложить правку

## Страница документации

Нажмите «Редактировать страницу» внизу страницы или измените файл в `src/content/docs/` и откройте pull request.

## Нормативный документ (устав, регламент, whitepaper)

1. Измените исходник `documents/<id>/v<версия>.typ`.
   Существенное изменение — новая версия: скопируйте файл в `v<новая>.typ` и добавьте её **первой** в `versions` в `meta.yaml`.
   Если правку готовили с ИИ, добавьте в документ раздел «Использование ИИ»: что подготовлено с ИИ и что проверено человеком. Если ИИ не применялся — так и напишите (Регламент использования ИИ, разд. 3).
2. Обновите пересказ документа в `src/content/docs/` — ссылка на него указана в поле `related` в `meta.yaml`.
3. Откройте pull request. Его одобряют ответственные из `.github/CODEOWNERS`.
4. После утверждения заполните в `meta.yaml` поля `date` и `approved`.

Старые версии не удаляются и не меняются: их хеши уже могли сохранить участники.

## Новый документ

Создайте папку `documents/<id>/` с `meta.yaml` (образец — `documents/charter/meta.yaml`) и исходником. Если исходника нет, положите готовый PDF и укажите его в поле `file` вместо `source`.
